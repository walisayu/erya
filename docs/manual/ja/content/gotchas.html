7 項目

💾 入力が消えるもの

ここを間違えると、打った文字が本当に消えます。

  1. 自動保存もクラッシュ復元もありません。保存していない内容はメモリーの中だけにあります。ターミナルを閉じる、SSH が切れる、マシンが落ちる——それで消えます。タブを閉じるときと終了するときに確認はしますが、防御はそれだけです。（1.1.7 参照）
  2. 確認行の Y は常に「破棄」です。質問を見て反射的に Y を押すのが、いちばん内容を失いやすい操作です。保存は S。3 つの確認行はどれも各文字の意味を同じ行に書いてあります。押す前に読んでください。（2.1.8 参照）
  3. 外部競合では O も R もどちらかを捨てます。O はディスク上の版を、R は手元の版を捨て、どちらも元に戻せません。迷ったら N でキャンセルし、別名で保存してから左右比較で統合します。（2.1.7 参照）
  4. 登録した定型文とマクロは保存しないと消えます。登録はメモリーに置くだけで、Erya が勝手に JSON を書くことはありません。終了前に「定型文を保存／マクロを保存」を実行してください。既定ではキーも割り当てられていません。（2.4.5 参照）
  5. 文字化けしているときは保存しないでください。文字コードの判定違いによる化けは、保存するとファイルに焼き付きます。F7 で正しい文字コードを見つけてから保存し、分からなければ保存せずタブを閉じます。ディスク上の原本は無事です。（4.3.7 参照）
  6. 比較の終了時に N を押すと、コピーした差分がすべて消えます。「N 破棄して終了」は、時間をかけて反映した差分をすべて捨てます。一時コピーは終了時に削除され、取り戻せません。（3.4.8 参照）
  7. バイナリファイルを編集する前にバックアップを。バイナリ形式には余裕がありません。長さが 1 バイトずれる、チェックサムを更新し忘れる、それだけでファイル全体が壊れます。まず別名で保存を。（3.3.7 参照）
5 項目

🔒 取り消せない・戻しにくいもの

戻すキーはありません。やり直すしかない項目です。

  1. 元に戻せるのは 100 手、しかも 1 文字が 1 手です。長い文章を打った後にまとめて戻す用途には向きません。1 手にまとまるのは、すべて置換・整形・段落の再整形・定型文の挿入・マクロの実行の 5 つだけです。（2.4.2 参照）
  2. 自動再読み込みで元に戻す履歴が消えます。未編集の文書が外部で変更されると自動的に再読み込みされ、元に戻す／やり直す履歴も一緒に消えます。古い手順は新しい内容に当てられないためです。最初は必ず驚きます。（2.1.7 参照）
  3. タブを閉じると履歴も消えます。履歴はタブに属します。同じファイルを開き直しても戻りません。（2.4.1 参照）
  4. すべて置換は事前に変更箇所を見せてくれません。F6 は確認もプレビューもなく実行します。検索文字列が短いときは特に危険なので、先に F3 でどこに当たるか確認してください。（2.3.6 参照）
  5. 比較の適用は元のファイルを直接上書きします。確認したらそのまま書き込まれます。Erya は外部で変更されていないかを確認するだけで、バックアップは残しません。（3.4.7 参照）
6 項目

🤫 何も知らせずに起きるもの

画面は止めませんが、結果は思ったものと違います。

  1. F7・F8 はステータス行を変えるだけ。変換は保存時です。文字コードも改行コードもその場では書き換わらず、次の保存で変換されます。逆に言えば、押し間違えても元に戻すか、もう一度押して戻せば済みます。（3.1.2 参照）
  2. F7 は表現できない文字コードを黙って飛ばします。次の文字コードで表現できない文字があると、Erya は何も言わずさらに次へ進みます。そのため 1 回押しただけで UTF-8 から GBK に飛ぶことがあります。（3.1.3 参照）
  3. 既定では 16 個の操作にキーがありません。定型文、マクロ、矩形の塗りつぶしと移動、段落の再整形、カーソル位置の表示——押しても何も起きないのが正常です。F1 ヘルプでもキー欄が空になっています。（4.4.6 参照）
  4. システム設定は記憶されません。F2 で選んだプロファイルと言語はその実行中だけ有効で、次回起動時には既定値に戻ります。固定したい場合は環境変数か設定ファイルを使います。（4.2.2 参照）
  5. 翻訳が足りないと無言で正體中文に戻ります。自作の翻訳に抜けがあると、その文だけ中国語で表示され、警告は出ません。日本語の画面に急に中国語が出てきたら、たいていは未翻訳です。（4.2.7 参照）
  6. 既定パスに設定ファイルがなくても警告は出ません。プラットフォームの既定位置に keymap.toml がない場合、Erya は黙って内蔵の既定値を使います。一方、--keymap や ERYA_KEYMAP で明示したパスが読めないときはメッセージ行に出ます。（4.1.7 参照）
5 項目

🔢 順序を間違えられないもの

手順が逆だと「押しても反応しない」ことになります。

  1. コピーする前に N で差分へ移動します。左右が同じ行にカーソルがあると、Shift+→ は「コピーできる差分ブロックがありません」と言うだけです。カーソルと「現在の差分」は別物です。（3.4.4 参照）
  2. 先に矩形選択を作ってから、埋める・動かすを実行します。選択がない状態では「先に矩形選択範囲を作成してください」と出るだけです。順序は Ctrl+B →矢印キー→操作キーです。（2.2.6 参照）
  3. 矩形選択の前に折り返し表示を切ります。折り返すと「何列目」が意味を失うため、両者は排他です。逆も同じで、矩形選択中は折り返しを有効にできません。（2.2.5 参照）
  4. マクロを実行する前に記録を停止します。記録中に実行すると「マクロを実行する前に記録を停止してください」と出るだけです。（2.4.6 参照）
  5. 差分をコピーしただけでは元のファイルは変わりません。コピー先は一時ファイルです。保存キーを押して Y で確認して初めて元のファイルが上書きされます。（3.4.7 参照）
6 項目

📌 いちばん忘れやすいもの

難しくはありませんが、つい忘れます。

  1. 保存にはファイルだけでなくディレクトリの書き込み権限も必要です。アトミック保存は元ファイルと同じディレクトリに一時ファイルを作るため、ファイルが書けてもディレクトリが書けなければ保存は失敗します。（2.1.6 参照）
  2. パス途中のディレクトリは自動作成されません。存在しないディレクトリへの保存はそのまま失敗します。先に外で作成してください。（2.1.5 参照）
  3. 定型文とマクロの JSON は文書のあるディレクトリに従います。ホームディレクトリではなく、編集中のファイルの隣に置かれます。プロジェクトを移ると前のセットは読めません。共有したいときは JSON をコピーしてください。（2.4.5 参照）
  4. 1 行 32 バイトの表示には 144 桁の幅が必要です。幅が足りないと W を押しても 16 バイトのままで、理由がメッセージ行に出ます。（3.3.3 参照）
  5. 大容量ファイルは比較もハイライトもできません。64 MiB 以上のファイルは左右比較に入れず、シンタックスハイライトも意図的に無効です。（3.2.2 参照）
  6. マクロが記録するのは操作ではなくキーです。キープロファイルを変えると、古いマクロはまったく別の動きになることがあります。マクロファイルを共有するときは同じプロファイルで。（2.4.7 参照）
8 項目

🧭 画面と用語の罠

他のエディターと違うところです。

  1. Ctrl+C はコピーで、中断ではありません。終了は Ctrl+X です。Erya の中で Ctrl+C を押しても終了しません。タブを閉じるのは F11、終了は Ctrl+X です。（1.1.7 参照）
  2. Ctrl+A は行頭への移動で、全選択ではありません。Erya に全選択の操作はありません。全体を選ぶには Ctrl+Home のあと Ctrl+Shift+End を使います。（2.2.4 参照）
  3. Ctrl+Y と Ctrl+R は 2 つのプロファイルで意味が逆です。Terminal Safe では Ctrl+Y がやり直し、Ctrl+R が置換。Erya Classic では Ctrl+Y が行削除、Ctrl+R がやり直しです。切り替え後にいちばん押し間違えやすい組です。（4.1.2 参照）
  4. ファイルダイアログの Esc はキャンセルで、親フォルダーへは戻りません。親へ戻るのは ← か Backspace です。Erya の Esc はどの画面でも「この画面から出る」です。（2.1.2 参照）
  5. ステータス行の「列」は画面上の桁ではなく文字数です。全角文字は画面上 2 桁を使いますが、文字としては 1 つです。Ctrl+G の入力もステータス行と同じ数え方です。（2.2.3 参照）
  6. 比較の差分件数は行数ではなくブロック数です。連続して変更された 5 行は 1 ブロックです。N はブロック単位で飛び、コピーもブロック単位です。（3.4.3 参照）
  7. バイナリファイルの 16 進数表示は Esc で戻れません。戻れるテキスト編集が存在しないためです。Esc は出口をもう一度伝えるだけ：F11 でタブを閉じる、Ctrl+X で終了。（3.3.5 参照）
  8. Erya のクリップボードはシステムのものとは別です。Ctrl+C でコピーした内容は Erya の中だけで流通します。他のプログラムとやり取りするにはターミナル自体のコピー＆ペーストを使ってください。（2.2.7 参照）
