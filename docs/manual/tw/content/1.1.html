1.1.1

這本手冊怎麼讀

四個部分、十四章，不必從頭讀到尾。

手冊分成四部：第一部講觀念與安裝（爾雅是什麼、怎麼裝、畫面怎麼看）、第二部講基本編輯（開檔、打字、搜尋、復原）、第三部講進階功能（編碼、大型檔案、十六進位、雙欄比對）、第四部是設定與附錄（改快捷鍵、換語言、查表）。

編號規則是「部-章」，例如 3.4 是第三部第四章；章裡面的小節再加一碼，例如本節是 1.1.1。內文寫「見 4.1」就是叫你翻到第四部第一章，左邊選單點得到。

三種讀法

  • 第一次用爾雅：把第一部 1.1 到 1.3 讀完，再讀 2.1（開檔與儲存）。四章讀完就能正常工作了。
  • 已經會用其他編輯器：直接看 1.3（畫面）與 4.4（快捷鍵一覽），需要什麼再回頭翻。習慣 nano 或 vim 的人記得先看 4.1，換一套按鍵配置比重新學快得多。
  • 只是臨時要開一個檔來看：1.2.5 講怎麼啟動，1.3 講畫面，Ctrl+X 離開。三分鐘。
搜尋怎麼用

左上角的搜尋框（或按 ⌘K / Ctrl+K）會做兩件事：一是把本章內文的關鍵字標成黃色，按 Enter 逐一跳過去；二是列出其他章節裡談這個主題的篇章，直接點就跳過去。畫面示意圖上的字也在搜尋範圍內。

手冊裡出現 Ctrl+S 這種標示代表按鍵，~/.config/erya/keymap.toml 這種灰色標示代表檔案路徑或指令。要注意的是爾雅的快捷鍵可以整套換掉（見 4.1），手冊一律以內建的 Erya Terminal Safe 預設配置為準；如果你換過配置，實際按鍵請以畫面第二列的提示列與 F1 說明為準——那兩個地方顯示的永遠是你當下真正在用的鍵。

這份手冊描述「現況」

內容依照目前的程式碼撰寫，不寫規劃中的功能，也不寫「應該要怎樣」。看到某個功能在手冊裡被標成「預設沒有綁按鍵」或「這個模式下不支援」，那就是現在的實際狀況。

1.1.2

爾雅在做什麼、不做什麼

一句話：它是一套跑在終端機裡、為中文文件而寫的文字編輯器。

爾雅 Erya 的名字取自「爾，近也；雅，正也」，是三十年前 DOS 上《漢書》中文文書系統的 Rust 重生。它以規格驅動、文件先行的方式從零重寫，不含原《漢書》的任何原始程式碼或資產，與原開發團隊也沒有隸屬關係。

它跑在終端機裡（Terminal、iTerm2、Windows Terminal、SSH 連線都算），啟動之後佔滿整個視窗，離開之後把視窗還原成原本的樣子。畫面長這樣：

爾雅做這些爾雅不做這些
開啟、編輯、儲存純文字檔 排版、字型、粗體斜體（它不是 Word）
UTF-8／UTF-8 BOM／Big5／GBK／Shift_JIS 的偵測與轉換 UTF-16、UTF-32 等寬字元編碼（開啟時會直接回報不支援）

最常見的誤會

爾雅沒有「自動存檔」，也沒有離開時的暫存還原。沒有按過 Ctrl+S 的內容只活在記憶體裡。它會在你關頁籤或離開時攔下來問你要不要存（見 2.1.8），但如果整個終端機被關掉、SSH 斷線、機器當掉，未存的內容就是沒了。

1.1.3

和 vim、nano 有什麼不一樣

最短的答案：不用背模式，而且中文是第一等公民。

終端機編輯器不缺，爾雅想解決的是很具體的一組問題：中文文件在終端機裡常常對不齊、編碼常常轉壞、舊檔案常常是 Big5。所以它在幾件事上跟其他編輯器不一樣。

1.1.5

一份文件的一生

從開啟到寫回磁碟，會經過這五站。

  1. 開啟。啟動時在命令列後面接檔名，或在編輯器裡按 Ctrl+O 叫出檔案對話盒。同一個路徑如果已經開在某個頁籤，爾雅會直接切過去，不會重複開兩份（2.1.1）。
  2. 判斷型態。爾雅會先看檔案多大、前 8 KiB 有沒有 NUL 位元組，再決定用哪一種模式打開，同時把編碼猜出來（3.1.1）。
  3. 編輯。一般文字檔在這裡度過大部分時間。每個頁籤各自保有自己的游標位置、搜尋條件與最多 100 步的復原紀錄（2.4.1）。
  4. 轉格式（可略過）。要把 Big5 舊檔轉成 UTF-8、或把 CRLF 換成 LF，就在存檔前按 F7／F8。轉換不會立刻寫檔，是在下一次儲存時才生效（3.1.2）。
  5. 儲存。Ctrl+S 會先寫到同目錄的暫存檔、再原子換掉原檔，Unix 上還會保留原本的檔案權限（2.1.6）。

1.1.7

先記住這六件事

看完全書會再遇到，但先在這裡放著。

  1. 沒有自動存檔。爾雅不會幫你偷偷存檔，也沒有崩潰還原。Ctrl+S 是唯一寫入磁碟的動作（2.1.5）。
  2. 離開是 Ctrl+X，不是 Ctrl+C。Ctrl+C 在預設配置裡是「複製」，不是中斷程式。真正的離開鍵是 Ctrl+X，關頁籤是 F11（2.1.3）。
  3. 快捷鍵可以整套換掉，所以手冊寫的不一定等於你按的。畫面第二列與 F1 顯示的永遠是你當下真正在用的鍵（4.1）。
  4. 編碼與換行是「下一次儲存」才生效。按 F7／F8 只是換掉狀態列上的標示，檔案要等你存檔才真的變（3.1.2）。
  5. 有三種模式不能編輯內容。大型檔案唯讀模式、十六進位檢視（對文字檔而言）、串流二進位檔案。狀態列會直接寫出來你在哪一種（3.2、3.3）。
  6. 矩形選取和自動換行不能同時用。兩者的座標系統會打架，所以爾雅讓它們互斥；開著一個時想開另一個，會被訊息列擋下來（2.2.5）。
