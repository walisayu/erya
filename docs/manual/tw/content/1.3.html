1.3.1

畫面的四條橫列

上面兩列、下面兩列固定，中間全部給你的文件。

不管你在哪一個畫面——編輯、開檔、比對、十六進位、設定——版面永遠是同一套：四列框架加中間的內容區。認得這四列，就不會迷路。

兩列在上、兩列在下，是刻意的

上面兩列回答「我在哪、我能按什麼」，下面兩列回答「現在是什麼狀態、剛剛發生了什麼」。卡住的時候，先看第 2 列有沒有你要的鍵，再看最後一列它有沒有跟你說話。

1.3.2

第一列：頁籤與標題

在編輯畫面它是頁籤列，在其他畫面它是畫面名稱。

爾雅 Erya │ [報告.txt*] 附錄.md nginx.conf
（編輯畫面：開了三個頁籤，正在編輯第一個，而且還沒存）
  • 目前的頁籤用方括號框起來：[報告.txt]。
  • 檔名後面的星號代表還沒儲存：[報告.txt*]。存檔之後星號會消失。
  • 頁籤顯示的是檔名（不含路徑）；沒有檔名的新文件顯示 [未命名]。
  • 頁籤太多排不下時，左邊會出現 ‹ 表示前面還有，目前頁籤永遠看得到。

換到其他畫面時，這一列會改成畫面名稱，有些還會多帶一段資訊：

畫面第一列顯示
編輯 爾雅 Erya │ [報告.txt] 附錄.md
開啟檔案（Ctrl+O） 爾雅 Erya │ 開啟檔案 │ /home/user/docs（後面是目前目錄）
選擇比對檔案（F4） 爾雅 Erya │ 選擇左側檔案 │ /home/user
雙欄比對 爾雅 Erya │ 檔案比對
按鍵說明（F1） 爾雅 Erya │ 按鍵說明
系統設定（F2） 爾雅 Erya │ 系統設定
按鍵配置編輯器 爾雅 Erya │ 按鍵配置編輯器 │ Erya Terminal Safe（後面是配置名稱）
看到第一列不是頁籤，就代表你不在編輯畫面

這是最快的定位方法。想回到編輯，通常按 Esc 就行（見 1.3.7）。

1.3.3

第二列：提示列

它列的是「你現在按得動的鍵」，而且會跟著你的按鍵配置變。

編輯畫面的提示列固定列出七個最常用的動作：

F1 說明 Ctrl+S 儲存 Ctrl+W 搜尋 Ctrl+R 取代 Ctrl+B 矩形選取 Ctrl+K 剪行 Ctrl+X 離開
這一列顯示的是「你的」按鍵，不是手冊寫的按鍵

除了固定不變的 F1，其他六個都是從目前的按鍵配置抓出來的。換成 nano 配置之後，這一列會變成 nano 的鍵。所以：手冊和畫面不一致時，以畫面為準（見 4.1）。

換到其他畫面時，這一列會整條換成那個畫面的操作說明。這是爾雅沒有選單也不會迷路的原因：

畫面提示列內容
開啟檔案↑/↓ 選取　Enter/→ 開啟　←/Backspace 上層　Esc/Q 取消
單行輸入（搜尋、跳行…） Enter 確認 Esc 取消 ←/→ 移動游標 Backspace/Delete 刪除字元
取代輸入 Enter/F5 取代下一個 F6 全部取代 Esc 取消
十六進位檢視W 每列 16/32 O 位移 10/16 Ctrl+G/G 跳至位移 Ctrl+P/Esc 返回編輯
雙欄比對左右兩個檔名各佔一半（見 3.4.2）
按鍵說明 ↑/↓ 捲動 PageUp/PageDown 翻頁 Home/End 首尾 F1/Esc 返回
系統設定 ↑/↓ 切換項目 ←/→ 選擇 E 編輯按鍵 Enter 套用 Esc 取消
按鍵配置編輯器 ↑/↓ 選取 Enter 編輯 Delete 停用 S 另存新檔 Esc 返回
1.3.4

內文區與 ~ 記號

中間那一大塊，以及那些暗藍色的波浪號。

第一章　專案背景 　　本專案自二〇二六年三月啟動，目標是把既有的 　　文件系統整批轉成純文字格式。 ~ ~ ~
  • 暗藍色的 ~ 代表「文件到這裡就沒了」，不是空行。真正的空行是完全空白的一列。
  • 內文區的高度是視窗高度減 4。視窗拉高就看得更多。
  • 游標是終端機自己畫的，形狀（方塊、底線或直線）由你的終端機設定決定。
  • 選取範圍是灰底黑字；搜尋命中與比對差異則是黃底黑字。
  • 語法高亮會依副檔名自動套用（見 3.1.5）；選取的灰底會蓋在高亮顏色上面，不會互相干擾。
全形字算兩欄

爾雅依照終端機的欄寬計算位置：中文、全形標點與大部分 Emoji 佔兩欄，英數字佔一欄，Tab 依 Tab 寬度展開。所以中英混排時游標的位置是準的，狀態列的「欄」也是照字元數算，不是照位元組（見 2.2.3）。

1.3.5

倒數第二列：狀態列

用 │ 隔成五到七格，每一格都是「現在的事實」。

/home/user/docs/報告.txt │ 5:24 │ 插入 │ Markdown │ 自動換行 │ UTF-8 │ LF
格子例子意思
檔名/home/user/docs/報告.txt你開檔時給的路徑（不是只有檔名）。新文件顯示 [未命名]。
行:欄5:24游標在第 5 行第 24 個字元。兩邊都從 1 開始算。
模式插入五種可能，見下表。
語法Markdown只有認得出語法時才出現。純文字檔沒有這一格。
自動換行自動換行只有開啟時才出現（Ctrl+L 切換）。
編碼UTF-8下次儲存會用的編碼（見 3.1.2）。
換行LF下次儲存會用的換行格式（見 3.1.4）。

模式那一格的五種可能

顯示代表
插入打字會把後面的字往右推。預設就是這個。
覆寫打字會蓋掉游標所在的字（Insert 切換）。
選取目前有一般選取範圍。它會蓋掉插入／覆寫的顯示。
矩形選取目前有矩形選取範圍（見 2.2.5）。
大型檔案唯讀檔案超過 64 MiB，內容不能改（見 3.2）。

十六進位檢視與雙欄比對有自己的狀態列格式，分別在 3.3.2 與 3.4.2 說明。

1.3.6

最後一列：訊息列與顏色

顏色就是嚴重度：黃色是回報，白色是要你打字，紅色是要你做決定。

已儲存 報告.txt
搜尋文字：目標字串
文件尚未儲存：S 儲存後離開／Y 放棄變更／N 返回編輯
顏色代表例子
黃色剛剛做了什麼的回報，看過就算已儲存、已復原上次動作、找不到相符文字、已取消選取
白色正在等你輸入東西搜尋文字：、另存新檔：、跳至行／欄：
紅色正在等你做決定，不回答不會繼續文件尚未儲存、頁籤尚未儲存、外部檔案已有更新
看到紅色就先讀完再按鍵

爾雅只有三種紅色確認：離開前的未儲存確認（S／Y／N）、關頁籤前的未儲存確認（S／Y／N）、外部檔案被改過的存檔確認（O／R／N）。每一個字母的意思都寫在那一列上，按錯了有可能真的弄丟內容——尤其 Y 一律是「放棄變更」（見 2.1.8）。

訊息列在你下一次操作之後不一定會清掉，它會停在那裡直到有新訊息。所以看到一句訊息時，先確認那是不是剛剛發生的事。

1.3.7

六種模式，一個 Esc

編輯以外還有六個全螢幕畫面，回去的鍵都一樣。

畫面怎麼進去怎麼出來詳見
檔案對話盒Ctrl+O / F4Esc 或 Q2.1.2
雙欄比對F4 選完兩個檔Esc3.4
十六進位檢視Ctrl+PEsc 或 Ctrl+P3.3
按鍵說明F1Esc 或 F11.3.8
系統設定F2Esc4.2.1
按鍵配置編輯器系統設定裡按 EEsc 回設定4.1.4

另外還有兩種不佔滿整個畫面的狀態，只影響最後一列：單行輸入（搜尋、取代、跳行、另存新檔…）與確認（紅色那些）。兩種都可以用 Esc 取消。

Esc 一律是「往回一層」

在編輯畫面它取消選取，在輸入列它取消輸入，在任何一個全螢幕畫面它回到上一層。不確定自己在哪裡、也不想改壞任何東西的時候，按 Esc 一定是安全的。唯一的例外是二進位檔案的十六進位檢視——那裡沒有文字編輯可以回去，按 Esc 只會在訊息列告訴你離開的方法（見 3.3.5）。

1.3.8

F1 按鍵說明

爾雅沒有選單，這份清單就是它的功能總表。

爾雅 Erya │ 按鍵說明
↑/↓ 捲動 PageUp/PageDown 翻頁 Home/End 首尾 F1/Esc 返回
F1 開啟或關閉按鍵說明 Up / Down / Left / Right 移動游標 Shift+Up/Down/Left/Right 延伸或反向縮減選取範圍 PageUp / PageDown 向上或向下翻頁 Home / End 移到目前行的開頭或結尾 Ctrl+Home / Ctrl+End 移到文件開頭或結尾 Ctrl+N 新增空白頁籤 Ctrl+O 在新頁籤開啟檔案
按鍵說明 │ 1-8 / 62
F1 為固定說明鍵，不受自訂快捷鍵設定影響
  • 左欄是按鍵、右欄是說明，可以用 ↑↓、PageUpPageDown、HomeEnd 捲動。
  • 狀態列顯示目前看到第幾筆／共幾筆。
  • 前十筆是固定不可改的按鍵（方向鍵、Enter、Backspace、Tab、Esc 這些），之後才是可自訂的動作。
  • 清單裡顯示的是你當下真正在用的鍵。換過按鍵配置的話，這裡會跟著變。
  • 預設沒有綁按鍵的動作（常用語、巨集、矩形移動…）在這裡會顯示成空的，代表「有這個功能，但還沒有鍵可以叫它」（見 2.4.8）。
F1 永遠是 F1

其他每一個動作都能重新綁鍵，只有 F1 不行。這是刻意留的逃生門：就算你把配置改到面目全非，還是有一個鍵能叫出完整清單。

1.3.9

手冊怎麼標快捷鍵

一個小約定，避免你照著按卻沒反應。

  1. 手冊裡的 Ctrl+S 一律指「Erya Terminal Safe 這套配置底下的儲存鍵」。這是內建的預設配置，剛裝好沒改過就是它。
  2. 如果你換過配置，請用動作名稱去對照。每個功能在程式裡都有一個固定的動作名稱（例如儲存是 save），4.4 的對照表兩邊都列了。改設定檔時要寫的也是這個名稱（見 4.1.5）。
  3. 畫面永遠是最終答案。第二列提示列與 F1 說明顯示的是你當下的鍵；兩者跟手冊不一致時，以畫面為準。
為什麼預設不是 Ctrl+Q 這種常見組合

因為終端機不是每一個組合鍵都收得到。macOS 保留了 Ctrl+功能鍵、Alt 組合常被拿去輸入特殊字元、修飾方向鍵（Ctrl+← 這類）在很多終端機裡根本傳不進來。預設配置刻意避開了這些，所以它在最多的終端機上都按得動，代價是少數進階功能預設沒有綁鍵。原本那套完整綁定改名為 Erya Classic 保留下來，隨時可以換回去（見 4.1.1）。
