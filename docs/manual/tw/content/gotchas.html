7 條

💾 會弄丟內容的

這幾條錯了，打的字就真的不見了。

  1. 沒有自動存檔，也沒有崩潰還原沒按過儲存的內容只活在記憶體裡。終端機被關掉、SSH 斷線、機器當掉，就是沒了。關頁籤與離開時爾雅會攔下來問，但那是唯一的一道防線。（見 1.1.7）
  2. 確認列的 Y 一律是「放棄變更」看到問句反射性按 Y 是最容易弄丟內容的動作。要存檔請按 S。三個確認列都把每個字母的意思寫在同一列上，按之前讀一下。（見 2.1.8）
  3. 外部衝突按 O 或 R 都會弄丟一邊O 蓋掉磁碟上那一版，R 丟掉你手上這一版，兩個都不能復原。不確定就按 N 取消，再另存一份，之後用雙欄比對合併。（見 2.1.7）
  4. 常用語與巨集收錄之後沒存檔就沒了收錄只是放進記憶體，爾雅不會自動寫 JSON。離開前要執行「儲存常用語／儲存巨集」，而那兩個動作預設還沒有綁按鍵。（見 2.4.5）
  5. 亂碼的時候不要存檔編碼猜錯造成的亂碼，一存檔就寫死進檔案了。先按 F7 找到正確編碼，確認內容正常再存；不確定就關掉頁籤不存，原檔還是好的。（見 4.3.7）
  6. 比對離開時按 N 會放棄全部暫存變更「N 放棄並離開」丟掉的是你抄了半天的所有差異。暫存副本在離開後就清掉，救不回來。（見 3.4.8）
  7. 改二進位檔之前先備份檔案格式通常沒有容錯：長度差一個位元組、校驗值沒跟著改，整個檔就壞了。先另存一份再動手。（見 3.3.7）
5 條

🔒 不可逆或很難逆的

做了之後沒有回頭鍵，只能重來。

  1. 復原只有 100 步，而且一個字算一步連續打了一大段之後想全部退掉，復原不是好方法。只有全部取代、格式化、段落重排、插入常用語、執行巨集這五個是整批算一步。（見 2.4.2）
  2. 自動重新載入會清空復原紀錄乾淨的文件被外部改掉時會自動重載，原本的復原／重做紀錄一併清空——因為舊步驟套不回新內容。第一次遇到常會嚇一跳。（見 2.1.7）
  3. 關掉頁籤，復原紀錄就沒了紀錄跟著頁籤走，重新開檔不會恢復。（見 2.4.1）
  4. 全部取代不會先讓你看要改哪些F6 按下去就換完了，不會問也不會列清單。搜尋字串很短的時候（例如只有一個「的」）特別危險，先用 F3 走一遍看看命中哪裡。（見 2.3.6）
  5. 比對套用是直接覆蓋原始檔案確認之後就寫進原檔了。爾雅只會先檢查原檔有沒有被外部改過，不會另外留備份。（見 3.4.7）
6 條

🤫 做了不會提示的

畫面不會攔你，但結果跟你想的不一樣。

  1. F7、F8 只改狀態列，要存檔才真的轉按完編碼或換行格式沒有立刻生效，檔案要等下一次儲存才會被轉換。反過來說，按錯了直接復原或再按幾次轉回去就好。（見 3.1.2）
  2. F7 會靜默跳過表示不了的編碼目標編碼無法表示文件裡的某個字時，爾雅直接跳到下一種，不會特別說一聲。所以按一次有可能從 UTF-8 直接跳到 GBK。（見 3.1.3）
  3. 預設有十六個動作沒有綁按鍵常用語、巨集、矩形填滿與搬動、段落重排、顯示游標位置——按了完全沒反應是正常的。F1 說明裡這些動作的按鍵欄是空白的。（見 4.4.6）
  4. 系統設定不會被記住F2 改的按鍵配置與語言只影響這一次執行，下次啟動又是預設值。要固定請用環境變數或設定檔。（見 4.2.2）
  5. 翻譯缺字會靜默退回正體中文自己翻的語言少了幾句時，那幾句會直接顯示中文，不會有任何提示。所以介面裡突然冒出中文，通常代表那一句還沒翻。（見 4.2.7）
  6. 預設路徑沒有設定檔不會警告平台預設位置找不到 keymap.toml 時，爾雅安靜地用內建預設值。但明確指定的 --keymap 或 ERYA_KEYMAP 讀不到時會在訊息列講話。（見 4.1.7）
5 條

🔢 順序不能顛倒的

步驟顛倒就會「按了沒反應」。

  1. 先按 N 跳到差異，才抄得動游標停在兩邊相同的行上時，Shift+→ 不會有反應，只會說「沒有可複製的差異區塊」。游標和「目前差異」是兩件事。（見 3.4.4）
  2. 先建立矩形選取，再填滿或搬動沒有選取範圍就按填滿，只會得到「請先建立矩形選取範圍」。順序是 Ctrl+B → 方向鍵拉範圍 → 動作鍵。（見 2.2.6）
  3. 先關自動換行，才能開矩形選取兩者互斥，因為自動換行會讓「第幾欄」失去意義。反過來也一樣，矩形選取期間開不了自動換行。（見 2.2.5）
  4. 先停止錄製，才能執行巨集錄製中按執行只會得到「請先停止錄製再執行巨集」。（見 2.4.6）
  5. 抄完差異還要套用，原檔才會變所有互抄都寫在暫存副本上。要按儲存鍵再按 Y 確認，原始檔案才會被覆蓋。（見 3.4.7）
6 條

📌 最常漏掉的

不難，就是容易忘。

  1. 存檔需要「目錄」也可以寫原子儲存要在原檔的同一個目錄建暫存檔，所以檔案可寫但目錄不可寫時，儲存一樣會失敗。（見 2.1.6）
  2. 路徑中的目錄不會自動建立另存新檔到一個還不存在的目錄會直接失敗。先在外面 mkdir。（見 2.1.5）
  3. 常用語與巨集的 JSON 跟著文件目錄走存在「目前文件所在的目錄」，不是家目錄。換一個專案就讀不到上一個專案的常用語，要共用就把 JSON 複製過去。（見 2.4.5）
  4. 每列 32 位元組需要 144 欄的終端寬度視窗不夠寬時按 W 會維持 16 位元組，並在訊息列說明原因。（見 3.3.3）
  5. 大型檔案不能比對，也沒有語法高亮64 MiB 以上的檔案進不了雙欄比對，語法高亮也是刻意停用的。（見 3.2.2）
  6. 巨集記的是按鍵，不是動作換過按鍵配置之後，舊巨集重播的結果可能完全不同。要跟別人共用巨集檔，兩邊得用同一套配置。（見 2.4.7）
8 條

🧭 介面與名詞陷阱

跟別的編輯器不一樣的地方。

  1. Ctrl+C 是複製，不是中斷；離開是 Ctrl+X在爾雅裡按 Ctrl+C 不會結束程式。關頁籤是 F11，離開是 Ctrl+X。（見 1.1.7）
  2. Ctrl+A 是移到行首，不是全選爾雅沒有全選動作。要選整份請用 Ctrl+Home 再 Ctrl+Shift+End。（見 2.2.4）
  3. Ctrl+Y 與 Ctrl+R 在兩套配置裡意思相反預設配置的 Ctrl+Y 是重做、Ctrl+R 是取代；Erya Classic 的 Ctrl+Y 是刪除整行、Ctrl+R 是重做。換配置之後最容易誤按的一組。（見 4.1.2）
  4. 檔案對話盒的 Esc 是取消，不是回上一層回上一層是 ← 或 Backspace。爾雅的 Esc 在每一個畫面都是「離開這個畫面」。（見 2.1.2）
  5. 狀態列的「欄」是第幾個字，不是畫面上的第幾欄全形字佔兩個畫面欄位，但在狀態列只算一個字。Ctrl+G 輸入的欄位跟狀態列一致。（見 2.2.3）
  6. 比對的差異數量數的是區塊，不是行連著改的五行算一個區塊，N 一次跳過整塊，抄的時候也是整塊一起抄。（見 3.4.3）
  7. 二進位檔案的十六進位檢視按 Esc 回不去那個檔案沒有文字編輯可以回，Esc 只會再說一次離開方式：F11 關頁籤、Ctrl+X 離開。（見 3.3.5）
  8. 爾雅的剪貼區跟系統剪貼簿是兩回事Ctrl+C 複製的東西只在爾雅裡面流通。要跟其他程式互傳，得用終端機自己的複製貼上。（見 2.2.7）
