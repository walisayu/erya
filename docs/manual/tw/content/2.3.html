2.3.1

搜尋：Ctrl+W

Ctrl+F 也可以，兩個鍵預設都綁到搜尋。

Enter 確認 Esc 取消 ←/→ 移動游標 Backspace/Delete 刪除字元
搜尋文字：專案
  • 輸入列會帶出上一次搜尋的字串，直接按 Enter 就是再找一次。
  • 從游標目前的位置往後找，找不到就繞回文件開頭再找一輪。
  • 找到的話游標會跳過去，該處以黃底標出。
  • 搜尋字串留空按 Enter 會被擋下來：「搜尋文字不可為空」。
  • Esc 取消，游標留在原地。
爾雅的搜尋是「一模一樣」的比對

區分大小寫、不支援正規表示式、不支援萬用字元，你打什麼就找什麼。找 Error 不會找到 error。全形與半形也是不同的字，找「，」不會找到「,」——處理中文文件時這一點反而常常正好是你要的。

2.3.2

尋找下一個與繞回開頭

F3 一直按下去就對了。

  • F3 用上一次的條件往後找下一個，不必再打一次字。
  • 還沒搜尋過就按 F3，爾雅會直接幫你打開搜尋輸入列。
  • 找到文件結尾時自動繞回開頭繼續找，訊息列會說「已從文件開頭繼續搜尋；F3 尋找下一個」——看到這句就代表你已經繞完一圈了。
  • 整份文件都沒有時顯示「找不到相符文字」，游標不動。
怎麼知道自己繞了幾圈

爾雅不顯示「第 3 筆／共 12 筆」。判斷方法是看訊息列：一直是「找到相符文字」就還在往下走，出現「已從文件開頭繼續搜尋」就是繞回去了。

2.3.3

取代：Ctrl+R

問兩次：先問找什麼，再問換成什麼。

Enter 確認 Esc 取消 ←/→ 移動游標 Backspace/Delete 刪除字元
取代：搜尋文字：二〇二五
Enter/F5 取代下一個 F6 全部取代 Esc 取消
取代為：二〇二六

注意第二個輸入列的提示列換了：這時候你有三個選擇。

按鍵做什麼
Enter 或 F5取代下一個相符處，然後回到編輯。
F6整份文件全部取代，訊息列回報取代了幾處。
Esc取消，什麼都不改。
搜尋與取代打成同一個字會被擋下來

兩邊一樣時爾雅不會做白工，直接說「搜尋與取代文字相同；文件未變更」。這通常代表你打錯了其中一邊。

2.3.4

F5 取代下一個、F6 全部取代

條件記在頁籤裡，之後可以一直按。

  • 取代過一次之後，F5 就會用同一組條件繼續取代下一處，不必重新輸入。
  • F6 一次把剩下的全部換掉。
  • 還沒設定過條件就按 F5 或 F6，爾雅會幫你打開取代輸入列。
  • 取代到文件結尾時同樣會繞回開頭，訊息列顯示「已從文件開頭取代 1 處」。
  • 沒有東西可取代時顯示「找不到可取代的文字」。
逐一確認的取代這樣做

爾雅沒有「取代並詢問」模式，但 F3 與 F5 搭起來就是：F3 跳到下一個看一眼，要換就按 F5，不換就再按 F3。兩個鍵共用同一組搜尋條件。

2.3.5

訊息列會說的六句話

搜尋與取代幾乎所有回饋都在最後一列。

訊息意思
找到相符文字；F3 尋找下一個找到了，游標已經跳過去。
已從文件開頭繼續搜尋；F3 尋找下一個找到了，但已經繞回文件開頭。
找不到相符文字整份文件都沒有。檢查大小寫與全半形。
搜尋文字不可為空輸入列空白就按了 Enter。
搜尋與取代文字相同；文件未變更兩邊打成一樣了。
已取代 1 處；F5 取代下一個，F6 全部取代
已全部取代 N 處		取代成功，順便告訴你接下來能按什麼。
2.3.6

取代之後要復原

Ctrl+Z 就好，但要知道一步是多大一步。

  • 單次取代（F5）：一次 Ctrl+Z 回到取代前。
  • 全部取代（F6）：整批算一步，一次 Ctrl+Z 就全部復原，不用按 N 次。
  • 復原後可以用 Ctrl+Y 重做。
全部取代之前先想一下

F6 不會問你、也不會列出要改哪些地方，按下去就換完了。不確定時先用 F3 走一遍看看會命中哪些位置，尤其當搜尋字串很短（例如只有一個「的」）的時候。真的改壞了，Ctrl+Z 還在——但前提是你還沒存檔又離開。

2.3.7

常見錯誤

搜尋取代最常見的五個誤會。

現象原因與處理
明明有這個字卻找不到大小寫不同，或是全形／半形不同。爾雅是完全比對（2.3.1）。
想用 .* 這類樣式不支援正規表示式，那些符號會被當成一般字元去找。
一直找到同一個地方已經繞回開頭了。看訊息列有沒有出現「已從文件開頭繼續搜尋」（2.3.2）。
只想取代某一段裡的文字目前沒有「只在選取範圍內取代」。用 F3 ＋ F5 逐一處理（2.3.4）。
取代完發現改錯了Ctrl+Z。全部取代整批算一步（2.3.6）。
