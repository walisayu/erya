4.4.8

Glossary

Every term used in this manual, with the chapter that explains it.

TermIn one sentenceSee
TabOne of several open files, each with its own cursor, search terms, and undo history.2.1.3
Hint barRow 2, listing the keys that work on the current screen.1.3.3
Status barSecond from the bottom: filename, position, mode, syntax, encoding, line endings.1.3.5
Message rowThe last row. Yellow reports, white waits for input, red waits for a decision.1.3.6
Insert / overwriteWhether typing pushes text along or replaces the character under the cursor.2.2.8
Grapheme clusterWhat looks like a single character on screen; Erya's unit of movement and deletion.2.2.3
Block selectionA rectangular selection that can be filled with a character or shifted as a unit.2.2.5
Line wrapSoft wrapping that changes the display only, never the file. Exclusive with block selection.2.2.5
Paragraph reflowReal line breaks inserted into the file to fit a given width.3.1.8
PhraseA captured string inserted in rotation, stored as JSON.2.4.3
MacroA recorded key sequence replayed on demand, stored as JSON.2.4.6
Atomic saveWrite a temporary file beside the original and swap it in; a failure never leaves a partial file.2.1.6
External changeAnother program modified the file. Clean documents reload; modified ones ask first.2.1.7
EncodingHow text becomes bytes. Erya supports UTF-8, UTF-8 BOM, Big5, GBK, and Shift_JIS.3.1.1
Line endingsLF or CRLF; the last cell of the status bar.3.1.4
Large-file modeThe read-only reading mode used from 64 MiB up, which can follow a growing log.3.2
Sparse line indexOne file offset every 4096 lines, so a large file need not be loaded whole.3.2.3
Hexadecimal viewThe document laid out as bytes; read-only for text files.3.3.1
Binary fileA file with NUL bytes or undecodable content; opens straight into the byte view.3.3.5
NibbleHalf a byte. Changing a byte takes two hexadecimal digits.3.3.6
Difference blockConsecutive differing lines in a comparison, treated as one unit.3.4.3
Temporary copyThe working file used during a comparison; originals are untouched until you apply.3.4.1
Key profileA TOML file mapping actions to keys, swappable as a set.4.1
Action nameThe fixed identifier for a feature in a config file, such as save.4.4.2
Erya Terminal SafeThe default profile, avoiding combinations terminals do not deliver.4.1.1
Erya ClassicThe original 1.0 bindings, including every advanced action.4.1.2
Translation filelocales/*.toml, which decides the interface language and can be extended.4.2.5
